# 30 prompts para programadores en español (gratis)

Prompts probados para depurar, refactorizar, probar y documentar con cualquier asistente de IA.

**Gratis y de código abierto (MIT).** Úsalo en tus proyectos y en los de tus clientes.

## Qué incluye

- 30 prompts: 3 de cada una de las 10 categorías
- Marcadores como `[LENGUAJE]` o `[CÓDIGO]` para adaptarlos
- Cuándo usar cada uno

## Instalación

```bash
git clone https://github.com/carlosp5751258-lgtm/ctrlia-prompts-programadores.git
# abre prompts.md y copia el que necesites
```
